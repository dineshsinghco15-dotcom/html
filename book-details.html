Synopsis & Educational Scope

Even bad code can function. But if code is not clean, it can bring a development organization to its knees. Every year, countless hours and significant resources are lost because of poorly written code.

Noted software expert Robert C. Martin presents a revolutionary paradigm with Clean Code. Martin has teamed up with colleagues from Object Mentor to distill their best agile practice of cleaning code "on the fly" into a book that instills the values of software craftsmanship.
